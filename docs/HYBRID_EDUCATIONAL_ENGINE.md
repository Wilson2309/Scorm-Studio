# Motor híbrido
La extracción y preparación deterministas conservan fragmentos canónicos, excluyen metadatos administrativos y construyen planes respaldados por fuentes. El proveedor IA redacta contenido bajo contratos estructurados. El compilador valida identidades, opciones y referencias antes de permitir exportar.
Las fuentes se reciben en ejecución, no se incluyen documentos académicos en el código público. La validación técnica no sustituye la revisión pedagógica docente. Configuración de modelos y prompts conservada.
