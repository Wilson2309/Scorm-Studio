# Evaluación educativa
La evaluación debe apoyarse en evidencia del documento. Timeline solo evalúa orden cuando existe una secuencia justificada; el recorrido conceptual permanece exploratorio. Simulation usa decisiones con criterios y consecuencias respaldadas por fuentes; contenido ambiguo requiere revisión docente.
Quiz y Ruleta conservan respuestas, referencias y validación de calidad. Ninguna validación automática garantiza calidad pedagógica completa.
