# Motor SCORM
Quiz, Ruleta, Timeline y Simulation exportan paquetes SCORM 1.2 con manifest y recursos autónomos. Los adaptadores y validadores comprueban correspondencia con la revisión exportada. El runtime soporta comunicación con el LMS; ejecutar aceptación de scoring, progreso y recuperación en el LMS de destino.
Los tests usan documentos sintéticos. No se distribuyen paquetes generados ni contenido de docentes.
